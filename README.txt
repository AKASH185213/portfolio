L. AKASH — PORTFOLIO PROJECT
============================

HOW TO OPEN
1. Extract this ZIP to a folder, for example Desktop\akash_portfolio.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension if installed.
4. The website works without a build step or package installation.

PROJECT FILES
- index.html  : page structure and portfolio content
- style.css   : visual design, responsive layouts, motion and effects
- script.js   : project explorer, command palette, scroll effects and network animation
- assets/     : place your profile photo here

ADD YOUR PHOTO
1. Copy your portrait photo into the assets folder.
2. Rename the photo to: akash-photo.jpg
3. Refresh index.html in your browser.
If your photo is PNG, convert/save it as JPG or update the filename in index.html.

BEFORE PUBLISHING
- Add your real GitHub, LinkedIn, email and Instagram links in index.html.
- Add the actual CollegeConnect GitHub repository URL where indicated.
- Review all education and project details for spelling and accuracy.
- Create a real résumé PDF before enabling a résumé download button. The button is intentionally not shown until a real file exists.
- StudentAI and To-Do List are clearly labelled as in-progress/planned; update their status only when the facts change.

NOTES
- Uses Google Fonts when internet is available; fallback fonts will work offline.
- The neural-network background is drawn locally with Canvas and no external JS library.
- Respects the operating system's reduced-motion preference.
- The CollegeConnect live demo button opens the currently supplied URL.
